# Toque POO Ejercicio

Ejercicio práctico de Programación Orientada a Objetos (POO) desarrollado en Java/Kotlin, como parte de la formación en el SENA.

## 📋 Descripción

Este proyecto forma parte de los talleres del SENA y tiene como objetivo poner en práctica los conceptos fundamentales de la Programación Orientada a Objetos, incluyendo clases, herencia, encapsulamiento y polimorfismo.

## 🌿 Estructura de ramas

- **`main`** → Rama principal con la versión estable del proyecto.
- **`QA`** → Rama de pruebas e integración antes de pasar a producción.
- **`features/michael`** → Rama de desarrollo de Michael.
- **`features/diego`** → Rama de desarrollo de Diego.

## 🚀 Cómo clonar y ejecutar el proyecto

```bash
git clone https://github.com/Exhelsior/toque-poo-ejercicio.git
cd toque-poo-ejercicio
```

Abre el proyecto en IntelliJ IDEA y asegúrate de tener un JDK configurado (Project Structure > SDK) antes de ejecutarlo.

## 🔄 Flujo de trabajo

1. Cada desarrollador trabaja en su propia rama `features/nombre`.
2. Los cambios se integran primero a `QA` para pruebas.
3. Una vez validados, se fusionan a `main`.
